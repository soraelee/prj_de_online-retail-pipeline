# Slack 알림 구성 기록

## 1. 개요

2026-05-11에는 Airflow 운영 상태와 전일 Retail 지표를 Slack으로 전달하기 위한 알림 구성을 추가하였다.

주요 작업 범위는 다음과 같다.

| 구분 | 작업 내용 |
|---|---|
| Slack 공통 모듈 | Slack 메시지 전송, 일별 요약 메시지 생성, DAG 실패 메시지 생성 |
| 일별 요약 DAG | 매일 오전 8시 30분에 전일 요약 지표 Slack 전송 |
| DAG 실패 알림 | 주요 Airflow DAG에 실패 콜백 연결 |
| Docker 환경변수 | Airflow 컨테이너에서 Slack/DB 환경변수를 읽을 수 있도록 구성 |

---

## 2. Slack 공통 모듈

파일:

```
slack_notifier.py
```

### 2-1. 역할

`slack_notifier.py`는 Slack 알림에서 공통으로 사용하는 기능을 담당한다.

| 함수/클래스 | 역할 |
|---|---|
| `SlackNotifier` | Slack Webhook으로 메시지 전송 |
| `build_daily_summary_message` | 일별 데이터 요약 메시지 생성 |
| `build_failure_message` | Airflow 실패 알림 메시지 생성 |
| `fetch_daily_summary` | 전일 요약 지표 DB 조회 |
| `send_daily_summary_alert` | DB 조회 후 Slack 일별 요약 전송 |
| `notify_dag_failure` | Airflow `on_failure_callback`에서 호출되는 실패 알림 함수 |

### 2-2. 환경변수

Slack 및 DB 접속 정보는 환경변수로 주입한다.

| 환경변수 | 설명 |
|---|---|
| `SLACK_WEBHOOK_URL` | Slack Incoming Webhook URL |
| `SLACK_CHANNEL` | Slack 메시지를 보낼 채널 |
| `DB_HOST` | PostgreSQL host |
| `DB_PORT` | PostgreSQL port |
| `DB_NAME` | PostgreSQL database |
| `DB_USER` | PostgreSQL user |
| `DB_PASSWORD` | PostgreSQL password |

주의:

```
Slack Webhook URL은 외부에 노출되면 안 된다.
노출된 경우 Slack에서 Webhook을 재발급하고 기존 URL은 폐기한다.
```

## 3. 일별 Retail 요약 알림 DAG

파일:

```
app/airflow/dags/daily_retail_summary_alert.py
```

### 3-1. 실행 스케줄

최종 스케줄:

```
30 8 * * *
```

의미:

```
매일 오전 8시 30분 실행
```

초기에는 평일만 실행하도록 `30 8 * * 1-5`로 구성했으나, 이후 평일 조건을 제외하여 매일 실행되도록 변경하였다.

### 3-2. 실행 흐름

```
daily_retail_summary_alert DAG
↓
PythonOperator
↓
run_daily_summary_alert()
↓
send_daily_summary_alert(target_date)
↓
fetch_daily_summary(target_date)
↓
build_daily_summary_message(summary)
↓
Slack 전송
```

### 3-3. target_date 기준

현재 DAG에서는 Airflow의 `data_interval_end`를 기준으로 전일을 계산한다.

```python
target_date = (
    context["data_interval_end"]
    .in_timezone("Asia/Seoul")
    .subtract(days=1)
    .strftime("%Y-%m-%d")
)
```

따라서 `target_date`는 단순히 현재 날짜 기준 전일이 아니라, Airflow가 계산한 `data_interval_end` 기준 전일이다.

수동 실행 시에는 `data_interval_end`가 사용자가 기대한 현재 시각과 다를 수 있으므로, 필요하면 이후 `dag_run.conf`로 `target_date`를 직접 받는 방식도 고려할 수 있다.

## 4. 일별 요약 지표

Slack으로 전달하는 지표는 다음과 같다.

| 지표 | 기준 테이블 |
|---|---|
| 전일 전체 주문건수 | `mart_daily_orders.order_cnt` |
| 전일 전체 취소건수 | `mart_daily_orders.cancel_cnt` |
| 전일 신규 고객 수 | `dim_customer.first_purchase_at` |
| 전일 순 매출 | `mart_daily_orders.total_sales_amount` |
| 전일 고객 재구매율 | `mart_customer_repeat.repeat_customer_rate` |
| 전일 리턴 고객 수 | `mart_customer_repeat.repeat_customer_cnt` |

조회 기준:

```
target_date = 알림 대상 일자
```

### 4-1. 메시지 예시

```
일별 데이터 요약 (2026-05-10)
- 전체 주문건수: 1,234건
- 전체 취소건수: 56건
- 신규 고객 수: 78명
- 순 매출: 12,345.67
- 고객 재구매율: 42.15% (리턴 고객 321명)
```

## 5. DAG 실패 알림

주요 DAG의 `default_args`에 실패 콜백을 연결하였다.

연결 방식:

```python
"on_failure_callback": notify_dag_failure
```

적용 대상:

| DAG 파일 | DAG |
|---|---|
| `app/airflow/dags/hourly_retail_ingestion.py` | `hourly_retail_ingestion` |
| `app/airflow/dags/backfill_retail_jsonl.py` | `backfill_retail_jsonl` |
| `app/airflow/dags/backfill_retail_pipeline.py` | `backfill_retail_pipeline` |
| `app/airflow/dags/retail_pipeline_dag.py` | `retail_pipeline` |
| `app/airflow/dags/daily_retail_summary_alert.py` | `daily_retail_summary_alert` |

실패 알림에 포함되는 정보:

| 항목 | 내용 |
|---|---|
| DAG | 실패한 DAG ID |
| Task | 실패한 Task ID |
| Run ID | 실행 ID |
| 발생 시각 | 알림 생성 시각 |
| 오류 내용 | Airflow context의 exception |
| 로그 | 실패 task의 log URL |

## 6. Docker Compose 설정

파일:

```
docker-compose.yaml
```

Airflow webserver와 scheduler가 Slack 및 DB 환경변수를 읽을 수 있도록 설정하였다.

추가된 항목:

```
DB_HOST=postgres
DB_PORT=5432
DB_NAME=retail_pipeline
DB_USER=postgres
DB_PASSWORD=postgres
env_file:
  - ./config/.env
```

Slack 설정 파일:

```
config/.env
```

예시:

```
SLACK_WEBHOOK_URL=...
SLACK_CHANNEL=#alert
```

설정 반영 시 Airflow 컨테이너 재생성이 필요하다.

```
docker compose up -d --force-recreate airflow airflow-scheduler
```

## 8. 추후 개선 사항

추가로 개선할 수 있는 부분은 다음과 같다.

```
1. 수동 실행 시 dag_run.conf로 target_date 직접 지정
2. Slack Webhook URL을 git 관리 대상에서 제외
3. 실패 알림이 재시도마다 반복 전송되지 않도록 조건 정리
4. 일별 요약 데이터가 없는 경우 별도 메시지 문구 처리
5. Slack Block Kit 형식으로 메시지 가독성 개선
```
